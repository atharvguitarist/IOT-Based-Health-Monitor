# IoT-Based Health Monitor

Medical Reminder and Disease Detection System. Real-time vitals monitoring, smart medication reminders and cloud analytics, built so patients never miss a dose.

## Overview

An IoT-based healthcare solution that helps individuals manage their health by monitoring vital signs in real time and providing medication reminders. It pairs a smart pillbox for precise dosage with health-tracking sensors and a cloud platform for data storage and analysis.

## Key Features

- Smart pillbox with compartment-level dosage control and scheduled medication reminders
- Real-time vitals monitoring through sensor-based tracking of key health parameters
- Cloud data platform for storage and analysis of patient health history
- Alerts for missed doses and abnormal readings
- Multi-platform front end: website, Android and iOS touchpoints
